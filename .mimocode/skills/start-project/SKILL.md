# 启动项目

启动项目的完整开发环境，包括后端服务、前端服务、数据库初始化和依赖检查。

## 使用场景

当用户说"启动项目"、"启动"、"启动这个项目"、"启动项目 然后使用子代理 监控 现在来测试"等类似指令时使用此技能。

## 步骤

1. **检查项目结构**
   - 确认项目目录结构
   - 检查是否存在 `start.command` 或 `dev.sh` 启动脚本

2. **执行启动脚本**
   - 优先使用 `./start.command`（macOS）
   - 或使用 `./dev.sh`（开发模式）
   - 确保脚本有执行权限：`chmod +x start.command`

3. **验证服务状态**
   - 后端服务：检查 `http://localhost:8000` 是否可访问
   - 前端服务：检查 `http://localhost:3000` 是否可访问
   - 确认数据库连接正常

4. **输出结果**
   - 显示服务访问地址
   - 报告启动状态和任何错误

## 注意事项

- 确保端口 8000 和 3000 未被占用
- 如果端口被占用，先释放端口
- 检查必要的环境变量和配置文件
- 确保依赖已安装（`npm install` 或 `pnpm install`）
