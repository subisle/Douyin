# 检查MCP

检查MCP（Model Context Protocol）工具的使用情况，识别不正常或异常的使用模式。

## 使用场景

当用户说"检查mcp有哪些不正常使用"、"检查MCP"、"MCP检查"等类似指令时使用此技能。

## 步骤

1. **收集MCP使用数据**
   - 查看MCP工具调用日志
   - 分析工具使用频率和模式
   - 识别异常或重复的调用

2. **分析使用模式**
   - 检查是否有不必要的工具调用
   - 识别重复或冗余的操作
   - 评估工具使用效率

3. **生成报告**
   - 列出所有MCP工具使用情况
   - 标记异常或不正常的使用
   - 提供优化建议

4. **提供修复建议**
   - 针对异常使用提供解决方案
   - 建议更高效的工具使用方式
   - 推荐相关的技能或命令

## 注意事项

- 保护敏感信息，不要暴露API密钥或凭证
- 关注性能瓶颈和资源使用
- 确保工具调用的合理性和必要性
- 定期清理无用的工具调用日志
