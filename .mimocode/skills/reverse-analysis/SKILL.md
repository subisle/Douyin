# 逆向分析

执行逆向分析工作流，分析二进制文件、代码库或系统，提取关键信息和模式。

## 使用场景

当用户说"帮我逆向分析一下"、"逆向分析"、"reverse analysis"等类似指令时使用此技能。

## 步骤

1. **目标分析**
   - 确定分析目标（二进制文件、代码库、系统等）
   - 收集目标的基本信息
   - 制定分析计划

2. **数据收集**
   - 使用适当的工具收集数据
   - 分析文件结构、字符串、函数调用等
   - 识别关键模式和组件

3. **模式识别**
   - 分析代码结构和逻辑
   - 识别算法和数据结构
   - 理解系统架构和设计

4. **结果总结**
   - 总结关键发现
   - 生成分析报告
   - 提供建议和下一步行动

## 注意事项

- 遵守法律和道德规范
- 保护敏感信息和知识产权
- 确保分析过程的可重复性
- 记录所有分析步骤和发现
